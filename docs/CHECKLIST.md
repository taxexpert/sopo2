# 빠른 검증 체크리스트 — 수정 후 / 자가개선 루프용

전체 검증(정답지 건별 대조·환율 재수집)은 오래 걸리므로, 코드를 고칠 때마다는
아래 경량 체크만 돌립니다. **1분 안에 끝나야 정상**입니다.

## 0. 실행 방법

```bash
cp samples/fixtures/*.csv data/     # 최초 1회 — 환율 고정본 (SMBS 접속 불필요)
```

```bash
python tools/quick_check.py         # 전체 케이스 (특정 케이스만: python tools/quick_check.py shopee)
```

종료코드 0 = 통과, 1 = 실패(실패 목록 출력). **루프에서는 이 종료코드로 판정**합니다.

## 1. 자동 체크 (quick_check.py 가 수행)

| # | 항목 | 방법 |
|---|---|---|
| A | **원화를 제대로 파악했는가** | 케이스별 원화 총합·통화별 외화/원화 = `expected/summary.json` 확정값 |
| B | **input 전 건이 확인됐는가** | 완전성 등식: 반영 + 사유별 미반영 + 라인아이템 연속행 = 전체 데이터 행 |
| C | **2가지 이상 체크 방식** | ① 문서 자체 합계행 vs 건별 합산 (쇼피 19장 전수, Joom 선언합계) ② 건수 vs 수량 별도 대조 ③ expected 와의 대조 — 서로 독립된 근거 |

- A가 깨지면: 환율 조회·환산·반올림 중 무언가 바뀐 것. **의도된 규칙 변경이면 expected 를
  갱신하고 `samples/README.md` 변경 이력에 사유를 남긴 뒤** 다시 통과시킬 것.
- B가 깨지면: 행을 조용히 버리고 있는 것. 미반영에도 반드시 사유가 붙어야 함.
- C가 깨지면: 파서가 행을 놓치거나 중복 인식하는 것.

## 2. 수동 체크 — 구조적 pitfall (코드 수정 시 훑기)

| # | 함정 | 확인 |
|---|---|---|
| 1 | **새 시트가 사라짐** | `generate_excel()` 의 `keep_sheets` 에 등록했는가 (미등록 시트는 마지막에 삭제됨) |
| 2 | **큐텐 반기말 3곳 불일치** | `app.py` `_qoo10_reporting_month` / `excel_writer` 동명 함수 / `extra_docs` 신고행 — 셋이 같은 월을 반환해야 함. 한 곳만 고치면 '수집은 12월, 조회는 10월' RuntimeError |
| 3 | **JPY·IDR·VND 100통화 이중 환산** | 직접 ×100/÷100 금지. `round_applied_rate()`(계산) / `smbs_source_rate()`(시트 표시)만 사용 |
| 4 | **월평균을 일별 평균으로 대체** | 금지. 공식값 없으면 중단이 정상 동작 |
| 5 | **신고기간 필터 없음** (알려진 공백) | 주문내역 파일에 신고기간 밖 배송분이 섞이면 그대로 집계됨 — input 을 기간에 맞게 잘라서 넣거나, 필터 기능 추가 전까지 유의 |
| 6 | **시트명 제약** | 31자 초과·`[]:*?/\` 문자 시 엑셀 저장 실패. 스토어명 등 사용자 문자열은 정제 후 사용 |
| 7 | **플랫폼 추가 시 누락** | `docs/ARCHITECTURE.md` §5 체크리스트 17개 항목 — CLI(`process.py`)까지 |
| 8 | **환불 규칙 일관성** | refunded=미반영 / partially_refunded=전액 반영 / voided·미배송=미반영+사유 집계. 새 파서에도 동일 적용 |
| 9 | **시트 출력 필수항목 삭제 금지** | Joom·쇼피파이·라자다 시트의 필수 열/행은 사용자 지정 사항 — `docs/PLATFORMS.md` "시트 출력 필수항목" 표 참조. 간결화 명목으로도 빼지 말 것 |
| 10 | **미반영 행 배치 규칙** | 반영 건 → 합계(매출 반영) → refunded → voided·미배송 순. 각주로 대체 금지 |
| 11 | **숫자 셀 열 너비(### 방지)** | 금액 셀은 서식 표시폭(콤마 포함)보다 넓은 열에만. 좁은 괘선 열(너비 3~5)에 금액 기입 금지, 새 시트는 열 너비 명시 지정. `quick_check overflow` 가 자동 검사 |

## 3. 기타 좋은 습관 (추가 조건)

- **미반영 사유가 화면 로그와 시트에 보이는가** — 조용한 제외 금지
- **월평균 캐시 근거** — `data/monthly_exchange_rate_cache.csv` 의 `source` 가
  `SMBS_MON_AVG_OFFICIAL` 인 행만 유효
- **expected 변경은 항상 이력과 함께** — 회귀인지 의도된 변경인지 구분하는 유일한 수단
- **기존 케이스 불변 확인** — 한 플랫폼을 고쳤어도 quick_check 는 전 케이스로 돌릴 것
  (이번 환불 규칙 변경 때 쇼피파이만 값이 바뀌고 나머지 5케이스 불변임을 이걸로 확인)
