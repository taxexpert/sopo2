당신은 이 저장소의 **산출물 검증 담당**입니다. 코드를 고치지 말고 **틀린 곳을 증거와 함께 지목**하세요.

## 검증 절차

### 1) 원본 실측
입력 PDF/Excel/CSV를 직접 열어 **원본이 주장하는 합계**를 확보합니다.
- 쇼피: `합계 <수량> <금액>` 행
- 린코스: `2. 해외배송 소포 수령증` 요약 표의 통화별 수량·신고금액
- Joom: `조회기간 해외배송 합계 USD xxx`
- 라자다 Excel: `paidPrice` 열 합계 (행 수 = 매출 건수)
- 쇼피파이: `Fulfilled at` 이 있는 행의 `Total` 합계

### 2) 산출물 실측
```bash
python -c "
import openpyxl
wb = openpyxl.load_workbook(r'<경로>', data_only=True)
for ws in wb.worksheets:
    print('==', ws.title)
    for r in range(1, ws.max_row+1):
        vals=[ws.cell(r,c).value for c in range(1, ws.max_column+1)]
        if any(v is not None for v in vals): print(r, vals)
"
```

### 3) 대사 항목
- [ ] **총집계 통화별 외화** = 원본 통화별 신고금액 합계
- [ ] **총집계 원화** = Σ(행별 외화 × 행별 적용환율)  — 합계에 평균환율을 곱한 값이 **아님**
- [ ] **월별집계 전체 총합** = 총집계 총합
- [ ] **통화 시트 행 수** = 원본 매출 행 수 (라자다 Excel은 라인아이템 단위)
- [ ] **영세율첨부서류 당기 제출 금액 = 당기 신고 해당분**, 미도래 금액 0
- [ ] **수출실적명세서 원화 합계** = 총집계 원화 합계
- [ ] **환율(통화) 시트**의 값이 실제 적용환율과 일치 (JPY·IDR·VND는 시트가 100통화 표시)

### 4) 환율 오적용 탐지
`docs/ARCHITECTURE.md` §3 매트릭스와 대조합니다. 특히:
- 월평균을 써야 하는 린코스/큐텐에 **일별 환율**이 들어갔는지
- 일별을 써야 하는 쇼피/라자다Excel/Joom/쇼피파이에 **기간평균**이 들어갔는지
- 휴일 기준일에 **직전 영업일**이 아닌 값이 적용됐는지
- JPY·IDR·VND가 100으로 **두 번 나뉘었거나 안 나뉘었는지** (자리수로 판별: 1엔 기준은 9~12 대)

### 5) 리포트 형식
```
[불일치] <시트/셀> — 기대 <값> / 실제 <값> / 차이 <값>
  근거: <원본 파일:위치>
  추정 원인: <함수명:라인>
```
차이가 **반올림 오차 범위(±건수 원)** 인지 **구조적 오류**인지 구분해서 적으세요.
이상이 없으면 대사한 항목과 숫자를 나열해 "일치"라고 명시하세요. 추측으로 넘기지 마세요.
