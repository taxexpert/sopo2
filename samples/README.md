## 폴더 구조

```
samples/
├── fixtures/        환율 고정본 (일별 2025-09~2026-07 + 월평균) — 실행 전 data/ 로 복사하면 SMBS 접속 불필요
└── <케이스>/
    ├── input/       앱에 실제로 넣는 파일 — 이것만 처리 대상  (git 제외)
    ├── reference/   정답지·참고자료 — 처리 안 함  (git 제외)
    └── expected/
        └── summary.json   확정 숫자 + 검증 상태(status/verified_against/note)
```

```bash
cp samples/fixtures/*.csv data/     # 환율 고정본 사용법
```

## 미결정 사항 (기대값에 영향)

1. **원단위 처리** — 앱·기존 산출물(쏭샵 등)은 **반올림**, 실덱스 수기 정답지만 **버림**.
   실덱스 정답지 324,198과 앱 324,212의 14원 차이는 전액 규명됨:
   ① 정답지가 2026-04-06 환율을 다음 영업일 값(1507.2)으로 오참조 (+7원, 실제 04-06=1507.6)
   ② 버림 vs 반올림 (+7원)
2. **신고기간 밖 배송분** — 수니네 라자다 태국 파일에 7월 배송 3행(1,006.60 THB) 포함,
   정답지는 제외하고 집계. **앱에는 신고기간 필터가 없어** 그대로 돌리면 THB가 46,288원 커짐.
   expected 는 정답지(상반기만) 기준으로 기재.
3. **쇼피파이 환불 차감** — FRESORY #1015(3 USD)·PAVY #1011(19.75 USD) 미차감. 기존 미결정 그대로.
